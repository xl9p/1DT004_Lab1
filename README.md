# 1DT004_Lab1


## Build and Run
The project is managed by **Alire**, it is used to handle the project's metadata, packages, dependencies, etc.

To build the project use the command - `alr build`. The project is configured to build 4 binaries for each assignment: `cyclic`, `cyclic_wd`, `comm1`, and `comm2`.

To run the resulting binaries, execute - `alr run <binary>`.
